Briefing Mainlines

SkillOpt：将 Agent 技能参数化，告别手动编辑

这是对当前 Agent 开发范式的根本性改进——手动编辑指令是 Agent 行为不可靠的主要根源。SkillOpt 通过将技能作为可训练参数，在不改变模型权重的前提下提供有保证的优化过程，有望大幅提升 Agent 的可靠性和适应性。

Claude Sonnet 5 发布，社区高度关注但实际表现待验证

vllm：LLM 推理引擎的通用性 vs 深度优化困境

vllm 支持从 AMD 到 TPU、从 DeepSeek 到 GPT 的广泛硬件和模型，但其核心挑战在于：在保持广泛兼容性的同时，能否在关键硬件-模型组合上提供可验证的性能优势。这决定了它能否在 TensorRT-LLM 等竞品中脱颖而出。
