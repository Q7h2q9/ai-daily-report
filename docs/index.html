ThinkingBox：把数据库评分转化为 RL 奖励做智能体后训练

代表『可验证结构化评分即奖励』的训练路线，其价值取决于评分标准与真实任务目标的对齐程度；若对齐偏差，易引发奖励黑客，且单一博客来源缺独立复现。

Agent Lightning v1.0：轻量框架把 RL 训练挂接到真实 agent harness

工程范式从『重建 agent』转向『挂接现有 harness』，降低 agent RL 门槛；但 3,500 行抽象能否覆盖真实 harness 的异构复杂性、保持训练信号可控，尚待社区复现验证。

Novelty Bench：LLM 能否可信评判研究新颖性

提出有价值的元评估问题，但当前仅有标题级证据，尚不足以形成可操作结论，宜定位为待验证研究议题。

短期内（1-3个月）出现少量社区对 Agent Lightning 的试用与适配报告、对 ThinkingBox 奖励对齐问题的讨论，但均不足以形成确证结论；NVIDIA 6.4x 维持厂商单源状态，等待 MLPerf 官方披露；Novelty Bench 可能发布全文但影响力有限；整体维持『方向性信号强、证据强度弱』格局，agentic RL 工程范式讨论升温而落地验证滞后。
