NVIDIA Cosmos 3 Edge推进端侧机器人控制后训练

试图将云端训练叙事延伸至端侧，但大模型能力与端侧实时、低功耗、低成本约束之间存在结构性张力，短期更可能是生态卡位而非可规模复制的落地。
