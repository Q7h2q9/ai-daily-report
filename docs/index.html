手动修改指令/技能缺乏改进保证是代理行为不可靠的根源。SkillOpt在不改变模型权重的前提下，将技能参数化并纳入训练流程，代表了从'提示工程'向'技能训练'的范式转变，是提升代理可靠性的重要技术路径。
