LiteRT在Google自家生态（如Pixel、Android）中取得较好集成，但在第三方硬件厂商中推广缓慢，端侧AI框架继续维持碎片化格局；OpenAI与AWS的合作在6-12个月内吸引部分中型企业客户，但大型企业因数据治理和锁定担忧而谨慎，微软则通过加强Azure OpenAI服务进行竞争性回应，形成‘多云供应、微软主导’的微妙平衡。
